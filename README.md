# Equity Intelligence — Premium AI Research Dashboard

A Streamlit dashboard for building structured equity-research prompts using the existing question bank. Includes a dark premium UI, combined starter/imported ticker universe, prompt quality checks, AI-editor links, brief downloads, session research history, and an optional cached Yahoo Finance snapshot.

## Files

- `app.py` — runnable dashboard entry point.
- `modules/question_bank.py` — the existing prompt definitions and full prompt builder.
- `modules/prompts.py` — the existing Research Studio module retained for your main application.
- `modules/watchlist_unified_universe_reference.py` — a copy of the existing unified-universe watchlist code for reference; this dashboard does not replace that module.
- `requirements.txt` — Python dependencies.

## Run on Windows / Anaconda

1. Extract the ZIP into a folder, for example `C:\Users\YourName\SREE-ANALYSIS\ai_equity_research_dashboard`.
2. Open Anaconda Prompt in that folder.
3. (Recommended) Create and activate an environment:

   ```powershell
   conda create -n equity-research python=3.11 -y
   conda activate equity-research
   ```

4. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Start Streamlit:

   ```powershell
   python -m streamlit run app.py
   ```

6. Open the local URL Streamlit prints (usually `http://localhost:8501`).

## How to use

1. Use the sidebar to import a CSV, Excel, JSON, or TXT ticker list, or add symbols manually.
2. In Research Studio, choose a ticker and research task.
3. Set the horizon, risk comfort, and optional thesis.
4. Click **Generate Full Research Brief**.
5. Inspect the Prompt Radar and edit or download the full brief.
6. Open an AI tool and paste the full brief into its chat, then submit it. The dashboard cannot silently send prompts to external AI websites.

## Import file format

A CSV or Excel file can contain a `Ticker`, `Symbol`, `Stock`, `Stocks`, or `Code` column. If none is present, the first column is used. TXT files can contain one ticker per line; comma-separated ticker lists are also supported.

## Data and limitations

- The dashboard is designed to work without market-data access; prompt generation is local.
- The market snapshot is optional, uses `yfinance`, is cached for five minutes, and can fail if the source or network is unavailable.
- Imported tickers and recent briefs are held in Streamlit session state; download anything you need to retain.
- AI answers are generated by the external AI tool you choose, not by this Streamlit application itself.
- Research and education only; not financial advice.

## Integrating into the existing project

Do not delete your current app, `modules/datahub.py`, `modules/theme.py`, `modules/membership.py`, `modules/earnings_viz.py`, or other application modules. This ZIP preserves the current `prompts.py` and question-bank logic and provides a runnable dashboard entry point. After validating this entry point, the premium UI can be migrated into your existing navigation/router and connected to the app's real Data Hub stock universe.
